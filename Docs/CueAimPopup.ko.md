# 당점 · 큐각도 선택 UI

- 연습 및 멀티플레이의 기존 확대 당점 선택 화면에 공통 CueAimPopup을 사용한다.
- 화면 전체를 검정 90%로 어둡게 하고, 불투명한 어두운 당점 / 큐각도 탭을 표시한다. 본문에는 테두리와 사진 배경을 사용하지 않는다.
- 당점 공과 바닥선만 기존 큐 방향에 맞게 회전한다. 탭과 큐각도 측면도는 회전하지 않는다.
- 당점 탭은 기존 장비별 당점 범위를 유지한다. 조절 중 즉시 반영하고 손을 떼면 닫는다.
- 큐각도 탭은 0~80도 슬라이더, 고정 수평 바닥선, 공과 선 형태의 큐 미리보기를 표시한다. 슬라이더 조절 중 실제 큐 기울기를 갱신하고 손을 떼면 닫는다.
- 탭 전환은 팝업을 닫지 않는다. 초기화·적용 버튼과 하단 안내 문구는 없다. 바깥 배경 탭으로 닫을 수 있다.
- 큐각도는 실제 샷에 반영한다. 기울어진 큐의 아래 방향 충격과 당점의 모멘트로 수평축 회전을 만들고, 기존 ClothPhysics의 천 마찰이 수구를 휘게 한다. 별도의 방향 보정이나 목표 공 유도는 없다.
- 공 높이를 고정하는 기존 제약을 유지하므로 테이블 위에서 휘는 찍어치기(마세)이며 점프샷은 지원하지 않는다. 0도에서는 기존 수평 샷 계산을 그대로 사용한다.
- 연습 및 멀티플레이의 실제 샷과 예측 가이드는 동일한 3차원 충격을 사용한다. 각도가 있을 때는 직선 임시 가이드 대신 물리 예측 궤적을 표시한다.
- 멀티플레이의 충격 전송에는 기존 벡터의 Y 성분을 보존한다. MatchShotCommand 방식은 elevation(0~80도)을 함께 전달하며 과거 데이터의 생략된 값은 0도다.
- 물리 근거: 아래 방향 충격이 만드는 수평축 회전과 천 마찰에 의한 곡선 운동. https://drdavepoolinfo.com/physics_articles/Alciatore_SCIAM_article_posted_version.pdf

검증 도구: Unity 메뉴 Tools / Magic Online / Validate Cue Aim Popup. 별도 미리보기 씬에서 탭, 각도 변경, 손 떼기, 회전된 당점 입력을 검사하고 Logs/cue-aim-contact.png 및 cue-aim-angle.png를 렌더한다. 실제 계정 데이터를 변경하지 않는다.

물리 검증: Logs/masse.request 파일을 만들면 저장된 단일 씬의 편집 상태에서 빈 씬으로 전환하여 Play Mode 검증 후 원래 씬으로 돌아간다. 좌우 곡선, 각도 증가, 중심 타격, 높이 고정, 예상/실제 궤적 일치, 네트워크 직렬화를 검사한다. 결과는 Logs/masse-result.txt에 기록한다. 씬이 수정된 상태에서는 자동 전환하지 않는다.

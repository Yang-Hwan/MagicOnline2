# 리플레이 폴더

연습 저장 화면과 리플레이 화면의 맨 위에서 폴더를 선택합니다. 폴더가 많으면 목록을 가로로 드래그하거나 휠로 이동할 수 있습니다. 각 폴더는 제목과 함께 20개의 기록을 보관합니다.

- **+ 추가**: 이름을 입력하여 폴더를 만들고 바로 선택합니다. 같은 이름과 빈 이름은 허용하지 않습니다.
- **삭제**: 확인 후 선택한 폴더의 기록과 제목을 함께 지웁니다. 취소하면 유지됩니다. 기존 기록을 보관하는 기본 폴더는 삭제할 수 없습니다.
- **저장**: 선택한 폴더와 번호에 직전 샷(큐 움직임 포함)을 저장합니다. 폴더를 바꿔도 직전 샷은 유지됩니다.
- 리플레이에서 폴더를 바꾸면 현재 재생이 종료되고 새 폴더의 기록을 선택할 수 있습니다.
- 리플레이 패널의 왼쪽 세로 손잡이로 위치를 옮깁니다. 폴더, 설명/제목, 슬롯 두 줄, 버튼 순서의 5줄 배치입니다.

기존 PracticeReplays/slot01.bin~slot20.bin과 제목 파일은 기본 폴더로 사용하므로 이동하지 않습니다. 추가 폴더는 PracticeReplays/Folders/<생성 ID>/에 저장하고 name.txt에 표시 이름을 보관합니다. 사용자 입력 이름을 경로로 사용하지 않습니다. 기존 v1/v2 및 큐 움직임을 포함한 v3 리플레이 형식은 그대로 유지합니다.

# 멀티플레이 감정 연출 및 리플레이

멀티 감정 컨트롤러가 s5_10·s5_8·s5_9 및 s1_4에 싱글 연습과 같은 표시 컴포넌트를 연결한다. 감정 선택은 기존 권한 클라이언트의 category/seed/shotPosition 메시지를 유지한다. 점수·턴·물리·정산 로직을 변경하지 않는다.

- s1_4: 이전 멀티 초기화의 폭탄 제외 옵션을 제거했다. 두 발이 연달아 낙하하고 각각 섬광·충격파·불꽃·파편과 서서히 흩어지는 연기를 표시한다. SpriteRenderer와 SpriteMask 상태를 새 리플레이에 기록한다.
- 별도 생성되는 폭탄 루트는 `Sentiment s1_4 explosion`으로 식별해 리플레이의 월드 연출 수집 대상에 포함한다. 이전 루트 이름은 수집 대상에서 빠져 있었다.
- s5_10은 기존 감정 분류 5번의 애니메이션 후보이다. 분류 1번 분노가 선택될 때마다 재생되는 연출은 아니다. 기존 감정 선택 확률은 유지한다.

- s5_10: 수구 위치를 사용하지 않고 테이블 안의 세 지점을 타격한다. 기존 스프라이트 애니메이션을 `SentimentSpriteOverlay`에서 화면에 투영한다. UI Canvas의 sortingOrder는 32767이며 천 영역의 효과는 RectMask2D로 제한하고 해머는 자유롭게 움직인다. 원래 SpriteRenderer는 forceRenderingOff로 중복 그리기를 막는다.
- s5_8: 비·위쪽 한 줄의 먹구름은 전체 화면 Overlay Canvas에 표시한다. 번개·물 튀김은 기존처럼 테이블 지점에 표시한다.
- s5_9: 전달받은 수구 위치 주변에서 해골·뼈·안개·입자를 Overlay Canvas에 표시한다.
- 모든 새 Overlay Image는 raycastTarget=false이며 GraphicRaycaster를 추가하지 않는다.

리플레이는 기존 state-events 기록/재생을 사용한다. 새로 생성되는 Canvas/Image도 계층 감지로 추적하고, 동적으로 자른 Sprite는 원본 텍스처 ID와 rect/pivot/PPU로 저장한다. 프레임별 텍스처·메시 캡처를 추가하지 않는다. 에셋 목록을 재생성해 새 원본 아틀라스를 안정적인 ID로 참조한다. 에셋 목록 갱신 시 메모리의 조회 캐시도 무효화한다. 그래픽이 없는 RectMask2D 부모도 기록·복원해 해머 효과의 천 영역 제한을 유지한다.

s5_4 까마귀는 이동하는 egg 파티클 발사체가 점을 남긴다. 현재 발사체 위치에서 seed/time만으로 재시뮬레이션하면 과거 발사 위치를 복원할 수 없다. s5_4/AniCrowFly 자식 파티클은 실제 ParticleSystem.Particle 버퍼를 기록하는 기존 경로를 사용해 점의 개수·원래 위치·색상·크기·수명을 보존한다. 다른 단순 파티클의 가벼운 seed/time 경로는 유지한다. 이전 저장 파일에 기록되지 않은 입자 이력은 소급 생성하지 않는다.

검증 요청: `Logs/multiplayer-sentiment-replay.request`. 실제 Pavilion 씬에서 네 감정 객체를 복제한 격리 씬으로 멀티 컨트롤러의 3구·4구 연결 및 실제 상태 기록→바이너리 직렬화→역직렬화→재생/앞뒤 탐색을 검사한다. 외부 서버 접속이나 계정/코인 변경은 하지 않는다. 결과: `Logs/multiplayer-sentiment-replay.json`, 단계 렌더: `Logs/MultiplayerSentiments/`.

추가 검증(2026-11-23): 멀티 연출 저장·재생 143개, 상대 자명종 표시·저장·재생 33개, 공통 리플레이 25개를 통과했다. 해머가 네트워크 프레젠테이션 진입점에서 선택되고 망치 본체까지 재생되는지, 두 폭탄의 독립적인 낙하·폭발과 마지막 정리, 원본/리플레이 렌더 비교 및 탐색을 검사했다. 파티클 버퍼 재생 중 매 프레임 시드를 다시 설정하던 경고도 제거했다. 실제 두 PC 접속과 Windows 빌드는 이번 확인에 포함하지 않았다. 과거에 저장되지 않은 새 연출은 기존 리플레이에 소급 적용되지 않는다.

# 싱글 연습 s5_9 해골의 저주

로컬 3구·4구 연습의 s5_9에만 `PracticeSkullCurse`를 연결한다. 감정 선택/연출재생 및 자동 감정 재생이 전달하는 수구 위치를 기준으로 연출하며, 테이블 밖의 위치는 천 내부로 보정한다. 기존 멀티플레이와 다른 감정은 변경하지 않는다.

- 0~0.48초: 수구 주변에 보라색 안개가 모이고 눈이 빛나는 해골이 나타난다. 해골은 작게 흔들리며 떠 있다.
- 0.66초부터: 3종의 크기와 회전 방향이 다른 뼈 30개가 10개씩 세 차례에 걸쳐 떨어진다. 각각 약 0.30~0.405초 동안 하강하고 착지 후 튕기며 바깥쪽으로 흩어진다. 충돌 순간 보라색 섬광이 나타난다.
- 2.45초: 별도의 큰 뼈가 마지막으로 충돌한다. 일반 뼈의 2배 이상 크기와 큰 충돌 섬광으로 강조한다.
- 2.72초부터: 보라색 입자가 시간차를 두고 퍼진다. 해골·뼈·안개는 서서히 투명해지고 모든 입자가 사라진 뒤 4.4초에 정리한다.
- 테이블 메시·재질·텍스처·공 위치·물리는 변경하지 않는다. 모든 요소는 ScreenSpaceOverlay Canvas(sortingOrder 32767)의 Image로 표시해 HUD·공·큐대 UI보다 위에 그린다. 테이블 마스크는 제거했다. 메인 카메라로 수구 주변의 원래 월드 좌표·크기·회전을 화면 좌표로 투영한다. 모든 Image는 raycastTarget=false이고 GraphicRaycaster는 추가하지 않아 클릭을 가로채지 않는다.
- 중단, 다른 감정 선택, 새 샷, 화면 비활성화 시 모두 숨긴다. 반복 재생은 처음부터 시작한다. 스프라이트·렌더러·난수 배치는 한 번 생성해 재사용하며 프레임별 이미지 생성이나 게임 공용 난수 변경을 하지 않는다. 씬 종료 시 생성한 객체와 Sprite를 해제한다.

에셋: `Assets/Resources/Gameplay/Sentiments/SkullCurse/SkullAtlas.png`. 내장 image_gen으로 제작한 3×2 투명 RGBA 원본을 그대로 사용하며 Unity에서 셀별 Sprite를 생성한다. 생성 프롬프트는 `Docs/S5_9SkullCurse.prompt.txt`에 보관한다.

검증 요청: `Logs/practice-demolition.request`. 실제 연습 씬 복사본으로 3구·4구의 선택/재생·수구 위치·뼈 낙하·3종/30개 혼합·최종 큰 뼈·입자 소멸·중단·반복·원상복구를 검사한다. 보고서: `Logs/practice-demolition-validation.json`. 단계별 이미지: `Logs/Demolition/*-skull-*.png`. 원본 편집 씬은 저장하지 않는다.

2026-11-23 검증: 기존 연출 138개 및 s5_9 34개, 합계 172개 검사를 통과했다. 3구·4구 모두 수구 위치 전달·해골 등장·뼈 3종/30개·마지막 큰 뼈·입자 감쇠·종료·중단·반복을 확인했고, 종료 전후 원래 테이블 화면의 RGB 차이는 0이었다. 안개의 사각 경계는 내장 image_gen 편집으로 제거하고 수정 에셋으로 재검증했다. 비활성화 콜백은 편집기 복사 씬에서 직접 호출해 검사했다. Windows 빌드는 실행하지 않았다.

HUD 위 표시 변경 후 총 178개 검사를 통과했다. 3구·4구에서 Overlay 표시 순서, Image 입력 비간섭, 테이블 마스크 제거를 추가 검사했고, 기존 낙하·최종 충돌·소멸·중단·복원 검사도 통과했다. 단계 렌더링 동안만 Canvas를 검증 카메라로 연결하고 각 검사 종료 후 Overlay로 복구했다. 종료 전후 화면 차이는 0이었다.

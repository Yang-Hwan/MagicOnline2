# 프리미엄 큐대 3종

뇌신 큐·성운 큐·홍염 큐를 상점 상품으로 추가했다. 본체는 투명 배경 PNG이며, 번개·소용돌이·불꽃과 입자는 Unity에서 매 프레임 생성한다. 효과를 본체 그림에 고정하지 않았다.

| 상품 | 리소스 | 움직이는 효과 |
|---|---|---|
| 뇌신 큐 | Gameplay/PremiumCues/ThunderGod | 불규칙한 푸른 번개, 전류 입자, 보석 발광 |
| 성운 큐 | Gameplay/PremiumCues/Nebula | 보라·청록색 회전 광환, 별가루, 보석 발광 |
| 홍염 큐 | Gameplay/PremiumCues/CrimsonFlame | 불꽃 흐름, 잿불 입자, 보석 발광 |

이미지는 `Assets/Resources/Gameplay/PremiumCues/`에 저장했다. 기본 제공 이미지 생성 도구로 승인 시안의 물리적 큐대 본체만 생성하고, 투명 여백을 정리해 타격 끝의 축을 중앙에 맞췄다. 최종 생성 프롬프트는 `PremiumCueArtPrompts.json`에 보관한다. 원본 시안의 번개·소용돌이·불꽃을 게임 코드에서 다시 표현하므로 실제 표시와 정지 시안은 완전히 동일한 픽셀은 아니다.

## 상품과 장착

`020_premium_cues.sql`이 기존 상품을 유지하면서 3종을 보이는 판매 상품으로 등록한다. 초기 가격은 마이그레이션 실행 당시 판매 중인 기존 큐대의 최저 유료 가격을 따르며, 이번 로컬 적용 가격은 각각 보석 10개다. 관리자 사이트에서 가격·판매 여부를 수정할 수 있다. 파워·팔로스루·당점·준비시간 보정은 모두 0으로 두었다. 새 특수효과 때문에 경기 성능이 올라가지는 않는다.

기존 구매·재시도 중복 차감 방지·보유장비 장착 경로를 공유한다. 경기 등록 시 서버 장비 스냅샷의 `CueVisual`을 고정하고 두 참가자가 같은 스냅샷을 조회한다. 경기 중 장비를 바꿔도 진행 중인 경기의 큐대/효과는 바뀌지 않는다.

## Unity 구현

- `BottomMenuView.Shop.cs`: 상점 카드와 프리미엄 상품 확대 미리보기. 상세 화면에서도 애니메이션을 보면서 구매할 수 있다.
- `BottomMenuView.Inventory.cs`: 보유 큐대 카드의 움직이는 미리보기.
- `PremiumCueEffects.cs`: 3종 효과의 공용 기하 생성기와 UI Graphic. 클릭을 가로채지 않고 UI 마스크를 지원한다.
- `PremiumCueWorld.cs`: 경기의 기존 큐대 축·길이를 유지하며 카메라를 향하는 투명 본체와 가산 발광 효과를 표시한다. 현재 차례 선수의 큐대에 맞춰 바뀌며 힘 조절/샷 순간에 발광 강도가 반응한다.
- `ShotCtrl.cs`: 기존 DoubleTap/일반 큐대 경로를 유지하고 새 3종에만 위 표시를 적용한다.
- `PremiumCue.shader`, `PremiumCueUI.shader`: 경기와 UI용 투명/가산 발광 렌더링.

효과는 콜라이더를 추가하지 않고 전역 `UnityEngine.Random`을 사용하지 않는다. 물리·조준·샷 규칙·큐대 성능 수치는 바꾸지 않는다. 효과당 약 2,000~5,000개의 동적 정점으로 구성하고 공유 UI 재질 및 경기 메시/재질을 정리한다. 상점은 unscaled time, 경기는 game time으로 움직인다. 양쪽의 큐대 디자인과 효과 종류는 동일하고 개별 입자의 위상까지 네트워크로 전송하지 않는다.

## 검증

- `dotnet run --project Server/PremiumCues.Tests/PremiumCues.Tests.csproj`: 실제 PostgreSQL 임시 스키마에서 18개 검사. 3종 등록, 중복 생성 방지, 구매 재시도, 정확한 차감, 장착, 양측 스냅샷 일치, 경기 중 외형 고정을 확인한다.
- 기존 `ShopPurchase.Tests`: 69개 회귀 검사 통과.
- `python Server/GameApi/Run-PremiumCueSmoke.py`: 실행 중인 API·관리자 사이트에서 21개 HTTP 요청 검사. 검증 계정만 구매/장착하고 두 계정이 같은 스냅샷을 읽는지 확인한 뒤 해당 계정을 관리자 삭제 폼으로 정리한다.
- `Tools / Magic Online / Validate Premium Cues`: 독립 유니티 미리보기 씬에서 23개 검사와 4개 렌더링. 상점과 경기용 메시의 시간별 화면 차이, 클릭 통과, 정점 수 제한, 난수 상태 보존, 카메라 대응, 장비 교체 시 제거를 검증한다. 결과는 `Logs/PremiumCues`에 저장한다.

API와 관리자 사이트를 재시작해 상품 등록을 반영했다. Unity는 플레이를 종료하고 다시 시작하면 적용된다. 배포한 클라이언트에는 새 이미지·셰이더·코드를 포함한 새 빌드가 필요하다. 실제 두 클라이언트의 Photon 경기 전체 실행은 이번 검증에 포함하지 않았다.

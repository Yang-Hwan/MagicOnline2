# TableSet07 연습 모드 이식

원본: `D:\Make\Work\Unity\dangguu\MagicCushionSingle\MagicRenewal\MagicRenewal`

## 실행

- Consist 왼쪽 메뉴에서 위에서 두 번째 과녁 버튼을 누르면 3구연습/4구연습/리플레이 카드가 표시됩니다.
- 3구연습은 흰공·노란공·빨간공 각 1개, 4구연습은 흰공·노란공 각 1개와 빨간공 2개를 사용합니다.
- 리플레이는 초구 뿌리기를 생략하고 20개 저장 슬롯을 표시합니다. 저장된 번호를 누르면 재생을 시작합니다.
- 연습 화면 상단 왼쪽 메뉴 버튼으로 Consist의 연습 서브메뉴에 돌아옵니다.
- 이식한 씬: `Assets/Practice/Scenes/TableSet07.unity`.

## 구성

원본 씬과 연결된 모델, 텍스처, 재질, 물리 재질, 프리팹 및 TableSet06 런타임
스크립트 41개를 `Assets/Practice` 아래에 복사했습니다. 파일별 새 GUID를 발급하고
참조를 함께 변경했습니다. 기존 DOTween 및 TextMesh Pro 공용 의존성은 재사용합니다.
원본 프로젝트 파일은 변경하지 않았습니다. 원본 파일 SHA-256과 GUID 매핑은
`Docs/practice-import-manifest.json`에 기록되어 있습니다.

`MainSwipe.circleContents`는 아래에서 위 순서이므로 두 번째 버튼은 인덱스 3입니다.
`PracticeSceneFlow`에서 씬 이동을 담당합니다. 빌드 씬 목록에 연습 씬을 추가했으며
TagManager의 비어 있던 8~19 레이어에 원본 이름을 동일한 번호로 등록했습니다.

`PracticeMenuView`는 원본 `Assets/Common/Images/02_연습하기.png`의 카드 영역 3개를
각각 Sprite로 생성합니다. 실행에 쓰는 동일 이미지 사본은 `Assets/Resources/PracticeMenu/Cards.png`입니다.
원본을 수정하거나 글자·배경을 재생성하지 않고 세 카드 영역만 분리합니다.

원본 프로젝트의 저장 기록 13개와 제목을 `Assets/Resources/PracticeReplaySeeds`에 포함했습니다.
리플레이 첫 진입 시 현재 프로젝트의 persistentDataPath/PracticeReplays에 없는 슬롯만 복사합니다.
기존 슬롯은 덮어쓰지 않으며, 한 번 가져온 후에는 삭제한 기록을 자동으로 복원하지 않습니다.
새 연습 기록은 기존 저장 기능을 통해 같은 20개 슬롯에 저장할 수 있습니다.
3구·4구 연습에서는 하단 `저장하기`를 눌러야 20개 슬롯, 제목, 저장 및 재생 조작 패널이 표시됩니다.
`저장 닫기`는 재생 미리보기를 종료하고 패널을 숨깁니다. 샷 기록이 생겨도 패널은 자동으로 열리지 않습니다.
리플레이 메뉴는 기존처럼 저장된 슬롯 선택 화면을 바로 표시합니다.

연습 경기는 Player 1(흰 수구), Player 2(노란 수구)의 로컬 2인 방식입니다.
입장 시 목표 7점, 양쪽 점수/보유코인/현 이닝 코인을 0으로 초기화합니다.
3구는 상대 수구와 빨간공을 모두 맞히되 두 번째 목적구 접촉 전까지 쿠션을
3회 이상 맞혀야 성공입니다. 두 번째 목적구를 먼저 맞히면 실패입니다.
4구는 빨간공 두 개를 모두 맞히면 성공이고 상대 수구 접촉은 파울입니다.
득점 즉시 현재 선수에게 1점과 기존 기본 보상 100코인을 반영하며 득점자는 계속 칩니다.
기존 성공 연출/아이템의 추가 코인 보상도 현 이닝 코인에 반영합니다.
실패/파울 또는 20초 시간 초과 시 상대에게 턴을 넘기고 타이머와 수구를 바꿉니다.
자신의 다음 이닝이 시작되면 이닝 코인은 0으로 초기화하고 경기 점수는 유지합니다.
7점에 도달한 샷이 끝나면 승리 메시지를 표시하고 입력과 타이머를 중지합니다.
연습 경기에서는 보유코인을 정산하거나 상대 지갑에서 코인을 차감하지 않습니다.
되돌리기는 샷 이전 선수/점수/코인/턴을 복원합니다.

표시와 턴 이벤트 흐름은 `Assets/Scripts/Sight/Surface/Pavilion/PnlMatch.cs`를 참고했으며,
실제 연습 씬의 경로는 `Canvas/PnlMatch/PlayerBoxs/PlayerSelf` 및 `PlayerOther`입니다.
점수판 오브젝트 이름은 `HitCountBox`이고 숫자는 그 안의 `HitCnt/Txt`입니다.

마찰, 구름 저항, 스핀 감쇠, 쿠션 반사, 충돌 서브스텝, 조준선 예측 및 씬에 저장된
공/쿠션 설정은 원본 그대로 가져왔습니다. 원본 PhysicsMng가 연습 시 100Hz 수동
시뮬레이션을 적용하고 종료 시 기존 전역 물리 설정을 복원합니다.

씬 이동에 맞춰 종료 버튼을 연결하고, 종료 시 PoolCoach 이벤트 연결을 해제하며,
UI 비동기 작업을 취소하고 재입장 시 큐 입력을 초기화했습니다.

## 검증

Unity 메뉴 `Tools > Magic Online > Validate Practice Integration`으로 실행합니다.
현재 씬이 저장된 편집 상태에서 실행하며, 종료 후 원래 편집 씬으로 돌아옵니다.
로그인 없이 Consist의 실제 버튼 이벤트를 호출해 서브메뉴, 3구·4구 입장과 샷,
리플레이 진입, 저장된 모든 슬롯의 재생 및 매번 서브메뉴 복귀를 검사합니다.
누락된 스크립트/오브젝트 참조, 지원되지 않는 재질, 100Hz 물리 적용 및 종료 후
물리 설정 복원도 검사합니다. 결과 파일은 `Logs/practice-validation.json`입니다.

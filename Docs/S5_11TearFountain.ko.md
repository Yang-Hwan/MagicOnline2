# s5_11 눈물 분수

싱글 3구·4구 연습 및 멀티 감정 컨트롤러가 공유하는 `PracticeSentimentActor.ConfigurePracticeTableEffects`에서 s5_11에 `PracticeTearFountain`을 연결한다. 수구 위치는 기존 미리보기/감정 RPC가 전달하는 worldPoint를 사용한다. 점수·턴·공 물리·네트워크 메시지 형식은 변경하지 않는다.

- 0~0.5초: 눈물이 차오르는 울상 표정이 나타난다.
- 0.65~2.65초: 표정이 엉엉 우는 얼굴로 바뀌고 양쪽 눈에서 굵은 눈물 줄기가 포물선으로 뿜어져 나온다. 물줄기·물 튀김·타원 물결이 한 그림으로 이어진 4프레임 FountainLoop 스프라이트를 좌우 반전해 표시한다. 짧은 줄기를 이어 붙이거나 곡선 형상을 매 프레임 흔들지 않고, 고정 위치에서 프레임 사이를 교차 페이드해 물 하이라이트와 방울만 흐르게 한다.
- 2.72~3.1초: 눈물 줄기가 잦아든 뒤 눈에서 나온 한 방울씩 두 눈물이 떨어진다. 방울 크기는 기존 0.15depth에서 0.10depth로 줄였다. 3.1초에 분수 착지와 비슷한 크기의 물 튀김/물결로 전환되며 사라질 때 크기를 확대하지 않는다.
- 훌쩍이는 표정, 작은 물방울, 물결이 서서히 옅어지고 모든 그림이 사라진 뒤 4.6초에 정리한다.

원래 공과 테이블을 변형하거나 이동하지 않는다. 수구 주변 위치·크기·회전을 카메라로 화면에 투영하고, Canvas ScreenSpaceOverlay/sortingOrder 32767로 HUD·공·큐대 UI보다 위에 표시한다. 모든 Image는 raycastTarget=false이며 GraphicRaycaster를 추가하지 않는다. 반복은 처음부터 시작하고 다른 감정/새 샷/화면 비활성화 시 바로 숨긴다. 최초 만든 이미지·스프라이트는 재사용하고 씬 종료 시 해제한다.

에셋: `Assets/Resources/Gameplay/Sentiments/TearFountain/TearAtlas.png`. 내장 image_gen으로 생성한 3×2 투명 PNG 원본을 그대로 복사했으며 Unity에서 셀별 Sprite를 만든다. 프롬프트: `Docs/S5_11TearFountain.prompt.txt`.

리플레이는 기존 state-events의 Canvas/Image 상태와 런타임 Sprite 정의를 저장한다. 새 아틀라스는 리플레이 에셋 목록에 등록한다. 새로 저장한 파일의 재생·앞뒤 탐색에서도 눈물 줄기·표정 전환·큰 눈물·물결·소멸과 최상위 표시 순서를 복원한다. 경기 중 영상 캡처/텍스처 복사를 추가하지 않는다.

검증 요청: 싱글 `Logs/practice-demolition.request`, 멀티 저장·재생 `Logs/multiplayer-sentiment-replay.request`. 실제 씬 복사본/격리 씬으로 검사하며 원본 씬 저장, 계정·코인 변경, 외부 서버 접속을 하지 않는다. 단계 렌더는 `Logs/Demolition/*-tears-*.png`, `Logs/MultiplayerSentiments/*-s5_11-*.png`에 기록한다.

2026-11-23 최종 검증: 기존 연출 포함 싱글 216개, 멀티 저장·재생 99개(합계 315개)를 통과했다. 눈물 곡선 방향과 굵기를 보정한 최종 코드로 재검증했다. 멀티 3구·4구에서 양쪽 분수 줄기 40개 및 큰 눈물 2개가 해당 프레임에 복원되고 앞뒤 탐색·종료도 유지됐다. s5_11 최종 충돌 프레임의 원본/재생 렌더 평균 RGB 차이는 두 모드 모두 0이었다. 싱글 종료 전후 테이블 화면 차이도 0이었다. 아틀라스는 안정적인 리플레이 에셋 ID로 참조했다. 검증은 편집기 격리 씬 기준이며 외부 서버/두 PC 실접속 및 Windows 빌드는 실행하지 않았다. 새로 저장한 파일부터 새 연출이 기록된다.

연결형 분수 에셋: Assets/Resources/Gameplay/Sentiments/TearFountain/FountainLoop.png (내장 image_gen 원본 2×2 시트). 생성 프롬프트: Docs/S5_11FountainLoop.prompt.txt. 분수 표현은 40개 줄기 조각 대신 좌우 각 2개의 교차 페이드 Image를 재사용한다.

연결형 스프라이트 수정 최종 검증(2026-11-23): 싱글 220개, 멀티 저장·재생 99개(합계 319개)를 통과했다. 분수는 좌우 각각 완성된 스프라이트로 그리며 별도의 바닥 첨벙 이미지를 동시에 겹치지 않는다. 마지막 눈물은 눈에서 출발해 분수의 착지 자리로 떨어지며 첨벙은 0.27depth×0.20depth 고정 크기로 페이드한다. 원본/재생에서 연결형 스프라이트와 교차 페이드, 축소한 마지막 방울, 앞뒤 탐색을 확인했다. 종료 전후 원래 테이블 화면 차이는 0이었다. 실제 두 PC 실접속 및 Windows 빌드는 실행하지 않았다.

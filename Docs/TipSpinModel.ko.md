# 당점 회전·파워 지속 모델

2026-10-23. 싱글·대전·온라인 권한 측 샷 재구성·예상 궤적에 같은 회전 규칙을 적용한다.

- 초기 회전의 방향과 크기는 당점으로 정한다. 같은 당점에서 파워와 팔로스루를 바꿔도 초기 회전 충격량은 같다.
- 기준 회전량은 이전 방식의 파워 40% 샷이다. 중심 당점과 파워 0에서는 타격으로 회전을 만들지 않는다.
- 파워는 기존처럼 출발 속도를 정하며, 회전 유지 계수도 0.2~0.9로 증가시킨다.
- 별도의 회전 감쇠율은 `(1 - 유지 계수) × 1.5 / 초`이다. 갑자기 정지시키지 않고 지수적으로 줄인다.
- 천 마찰·구름 전환·쿠션·적구 충돌도 회전에 계속 영향을 준다. 유지 계수는 정확한 회전 종료 시간을 뜻하지 않는다.
- 팔로스루의 기존 출발 속도 보정과 적구 충돌 후 진행 보정은 유지하되, 새 방식의 회전 유지 계수에는 관여하지 않는다.

`FollowThroughProfile.SpinLeverScale`에서 파워에 비례하는 직선 충격량에 반비례하도록 유효 지렛팔을 보정한다.
따라서 `지렛팔 × 직선 충격량`으로 계산되는 회전 충격량에서 파워와 팔로스루 속도 보정이 상쇄된다.
이는 기존 유효 타점 계산을 확장한 게임 모델이며 실제 큐 접촉 위치를 이동하는 의미가 아니다.

## 이전 방식으로 복귀

`Assets/Practice/TutorialInfo/Scripts/TableSet06/Sight/Vital/FollowThroughProfile.cs`의
`UseIndependentSpin = true`를 `false`로 바꾸고 다시 컴파일·빌드한다.
기존의 파워 비례 초기 회전량과 파워·당점·팔로스루 회전 유지 공식을 함께 복원한다.
대전 양쪽은 반드시 같은 설정의 빌드를 사용한다. 새 방식은 Photon 접속 프로토콜에 `-tipspin1`을 붙여 구형 클라이언트와 분리한다.
실행 중에는 이 설정을 전환하지 않는다.

변경 직전 관련 소스 사본은 로컬 `Logs/SpinModelBackup/20261023-152428/`에 보관했다. 이 사본은 Git에 포함되지 않는다.
변경 전 상태의 로컬 Git 체크포인트는 `codex/before-tip-spin-20261023` 브랜치에 보관한다. 원격 푸시는 하지 않았다.

## 검증

Unity 메뉴 `Tools > Magic Online > Validate Spin Model`에서 다음을 검사한다.

- 파워 0~100%, 당점 0~100%, 팔로스루 0~100% 조합에서 회전 충격량의 파워·팔로스루 독립성
- 파워 0과 중심 당점에서 회전 충격량 0
- 파워 증가에 따른 유지 계수의 단조 증가와 실제 감쇠 후 남은 회전량 비교
- 이전 회전 유지 공식의 기존 경계값·보정량·감쇠 검사

수식 검사는 실제 게임의 천·쿠션·충돌을 포함한 샷 체감 검사를 대신하지 않는다.

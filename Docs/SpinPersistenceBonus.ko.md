# 회전 지속성 보너스 (2026-09-29)

기존 지속성 B = 0.4 + 0.6 × 파워 × 당점 편심을 유지합니다. 최종값은 min(1, B × (1 + 0.2 × 파워 가중치 × 팔로 가중치 × 당점 편심))입니다. 20%는 기존 계수에 대한 상대 증가율이며 실제 회전 시간 20% 증가를 뜻하지 않습니다.

파워 가중치는 0→0.4에서 SmoothStep으로 0→1, 0.4→1에서 1→0입니다. 팔로 가중치는 1-SmoothStep(0,1,팔로스루)입니다. 중심 당점과 파워 양 끝은 기존값을 유지하고 팔로스루 1에서는 보너스가 없습니다. 보너스는 감쇠만 줄이며 회전이나 타격 힘을 새로 더하지 않습니다. 기존 천 마찰, 충돌 보정과 팔로스루 속도 보정은 유지됩니다.

당점 편심 0.8, 팔로스루 0 예시:

| 파워 | 기존 | 보너스 적용 |
|---|---|---|
| 0.3 | 0.544 | 0.617 |
| 0.4 | 0.592 | 0.687 |
| 0.8 | 0.784 | 0.817 |
| 1.0 | 0.880 | 0.880 |

연습, 일반 대전, 새 대전의 샷 복원과 예측선에 공통 적용합니다. 물리 버전이 달라 일반 매칭 protocol은 pavilion-practice-physics-4, 새 대전 테스트는 practice-match-test-10으로 구분합니다. 두 클라이언트 모두 업데이트해야 합니다. 기존 리플레이는 저장된 프레임을 재생하므로 궤적이 바뀌지 않습니다.

검증: SpinPersistenceValidation에서 전체 파워/당점/팔로 범위의 보너스 상한, 기존값 보존, 팔로 감소, 0.4 최대 보너스와 연속성, 감쇠 개선 및 무회전 보존을 검사합니다.

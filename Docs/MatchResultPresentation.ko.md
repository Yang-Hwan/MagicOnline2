# 경기 종료 연출 순서

- 싱글 연습과 멀티플레이는 공통 PopMatchFinish에서 종료 표시를 조정한다.
- 마지막 득점 기술명은 등장 시점부터 최소 1초 읽을 시간을 확보하고 0.3초 퇴장한 뒤 결과를 표시한다. 득점 글자가 남아 있으면 해당 연출도 끝날 때까지 기다린다.
- 시간 종료, 상대 퇴장, 무득점 온라인 종료는 남아 있는 득점 연출을 정리하고 결과를 바로 표시한다. 서버 결과 확인에 필요한 시간은 별개다.
- 종료 표시를 요청한 이후에는 새 기술명과 득점 글자를 받지 않는다. 결과 창을 닫아도 차단을 유지하며 새 경기 초기화에서 해제한다.
- 연습 메뉴 복귀와 기존 멀티 재대결 화면 전환의 3초 대기는 결과가 실제 표시된 후 시작한다.
- 창이 비활성화되거나 닫히면 대기 중인 결과 표시를 취소한다.

검증: MatchResultSequenceValidation.Run — 무득점 즉시 표시, 기술명 대기와 퇴장 순서, 늦은 연출 차단, 시간 종료 우선 처리, 닫기 취소, 새 경기 초기화 등 13항목.

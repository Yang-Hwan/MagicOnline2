# 싱글 연습 s5_8 폭풍우

로컬 3구·4구 연습의 s5_8에 `PracticeTableStorm`을 연결한다. 기존 멀티플레이 및 다른 감정의 원래 애니메이션은 변경하지 않는다.

- 0~0.8초: 먹구름 5개(화면 위쪽 한 줄)가 좌우에서 테이블 위로 몰려든다.
- 0.55~1.05초: 빗줄기 96개와 물 튀김 24개가 점차 나타난다. 빗줄기는 화면 전체에 서로 다른 속도와 길이로 흐른다.
- 1.35초, 1.95초, 2.65초: 서로 다른 지점에 푸른 낙뢰와 충격 물 튀김이 나타난다. 번개는 짧은 이중 점멸 후 사라지고 테이블 위 색상 오버레이와 구름 명암으로 전광을 표현한다. 실제 조명 설정은 변경하지 않는다.
- 3.05초부터 비가 잦아들고 3.3초부터 구름이 옅어지며 바깥으로 이동한다. 4.8초에 종료한다.
- 테이블 메시·재질·텍스처·공 위치·물리·카메라를 변경하지 않는다. 구름·비·전광 오버레이는 ScreenSpaceOverlay Canvas(sortingOrder 32767)에 표시해 HUD 및 큐대 UI 위로 화면 전체를 덮는다. 아래쪽 구름 줄은 생성하지 않는다. 화면 크기 변경은 현재 Canvas 크기를 기준으로 반영한다. Image.raycastTarget=false이며 GraphicRaycaster를 추가하지 않아 UI 입력을 가로채지 않는다. 번개와 물 튀김만 천 영역의 스프라이트로 유지한다. 종료 시 원래 테이블이 그대로 드러난다.
- 중단, 다른 연출 선택, 새 샷, 화면 비활성화 시 모든 효과를 숨긴다. 반복 시 처음부터 재생한다. 최초 생성한 스프라이트와 렌더러를 재사용하고 프레임별 이미지 생성·검색·난수 호출을 하지 않는다. 씬 종료 시 생성한 객체와 Sprite를 해제한다.

에셋: `Assets/Resources/Gameplay/Sentiments/Storm/StormAtlas.png`. 내장 image_gen으로 생성한 2×2 RGBA 원본을 그대로 복사했으며 Unity에서 셀별 Sprite를 만든다. 프롬프트: `Docs/S5_8Storm.prompt.txt`.

검증 요청: `Logs/practice-demolition.request`. 실제 연습 씬 복사본으로 3구·4구의 선택/재생, 구름 이동·넓은 강우·낙뢰 세 차례·감쇠·자연 종료·취소·반복·원상복구를 검사한다. 원본 편집 씬은 저장하지 않는다. 보고서: `Logs/practice-demolition-validation.json`. 단계별 이미지: `Logs/Demolition/*-storm-*.png`.

2026-11-23 검증: 기존 s5_10·s1_4 검사 94개 및 s5_8 검사 36개, 합계 130개를 통과했다. 3구·4구 모두 넓은 강우·물 튀김·구름 이동·낙뢰 3회·자연스러운 감쇠·종료·취소·반복을 확인했다. 종료 전후 원래 테이블 이미지의 RGB 차이는 0이었다. 편집기 복사 씬에서 비활성화 콜백은 직접 호출해 검증했다. Windows 빌드는 실행하지 않았다.

화면 전체 날씨 및 HUD 위 표시 변경 후 138개 검사를 통과했다. Overlay Canvas의 표시 순서, 입력 비간섭, 화면 가로·세로 전체의 강우, 위쪽 구름 한 줄만 생성, 테이블 마스크 비적용을 추가 검사했다. Camera.Render는 Overlay Canvas를 캡처하지 않으므로 단계별 렌더 검증 동안만 같은 Canvas를 미리보기 카메라에 연결하고 각 모드 검사 후 Overlay로 복구한다. 종료 전후 화면 RGB 차이는 0이었다.

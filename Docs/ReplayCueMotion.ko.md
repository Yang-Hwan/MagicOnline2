# 리플레이 큐대 움직임 저장

새 저장 형식(version 3)은 매 프레임 공 상태에 더해 큐대 표시 여부, 월드 위치·회전, 당점 이동, 큐 슬라이드 위치를 저장한다. 실제 타격이 확정되어 큐가 수구를 향해 전진하는 마지막 스트로크 시작부터 기록한다. 조준·설정·기다림과 중단한 스트로크는 제외한다. 공 타격 시 마지막 스트로크와 이후 공·큐대 프레임을 같은 시간축으로 결합한다. 타격 직전 당겨진 위치, 전진 타격, 팔로스루, 회수 동작은 실제 실행된 Transform을 기록한다.

재생은 물리를 다시 계산하지 않고 저장된 프레임을 적용한다. 일시정지, 다음 프레임, 처음으로 이동에도 큐대 상태가 함께 적용되며 닫을 때 재생 전 공과 큐대, 컨트롤 상태를 복원한다.

메모리 제한: 타격 직전 버퍼는 최대 128 프레임(일반적으로 약 0.08초만 사용), 전체 기록은 최대 60,000 프레임이다. 이전 version 1/2 파일도 읽지만 큐대 동작 데이터가 없으므로 큐대를 숨기던 기존 동작을 유지한다. 새 저장 파일은 구버전 실행 파일에서 열 수 없다.

검증: PracticeIntegrationValidation의 실제 타격 애니메이션을 사용해 3구/4구 마지막 전진 스트로크·팔로스루 저장, 중단된 스트로크 제외와 타격 전 대기 구간 제거, 저장 후 불러오기와 프레임 선택에 따른 큐 위치, 기존 version 1/2 호환, 리플레이 종료 시 라이브 큐 상태 복원을 검사한다. 테스트는 사용자의 기존 슬롯 파일을 백업하고 복원한다.

검증 결과: 2026-09-27 전체 PracticeIntegrationValidation 통과(completed=true, passed=true). 3구/4구 실제 타격과 큐대 저장·재생, 이전 파일 형식 및 20개 슬롯, 대전 관련 회귀 검사에 오류 없음. 보고서: Logs/replay-final-stroke-validation.json.

## 리플레이 예상 두께

상단 두께 UI는 저장된 첫 프레임의 공 위치와 큐 방향으로 조준 당시 예상 두께, 공의 좌우 겹침, 공 색을 복원한다. 재생/일시정지/프레임 이동 중에도 타격 당시 값을 유지하고, 종료하거나 다른 기록을 열면 해당 표시를 초기화한다. 조준 경로에 적구가 없거나 쿠션이 먼저 가로막으면 연습 중과 같이 숨긴다. v3은 저장된 큐의 월드 방향을 사용하고 v2는 저장된 조준 회전을 사용한다. 조준 방향 정보가 없는 v1은 두께를 추정하여 표시하지 않는다. 파일 형식은 변경하지 않는다.

# 샷 대기시간 자명종

기존 HUD의 실제 남은 시간을 읽어 표시한다. 턴 제한시간이나 샷 판정은 바꾸지 않는다.

| 남은 시간 | 표정과 움직임 |
| --- | --- |
| 10초 이하, 8초 초과 | 심심한 표정. 몸체는 고정하고 눈만 움직인다. |
| 8초 이하, 4초 초과 | 짜증 표정. 8장 스프라이트와 작은 압축·복원으로 약하게 떤다. |
| 4초 이하 | 화난 표정. 8장 스프라이트를 더 빠르게 재생하고 떨림과 벨 간격을 강화한다. |

민트 몸체, 노란 벨, 크림색 얼굴과 짙은 남색 외곽선을 사용한다. 바깥 흰색 스티커 테두리는 제거했다. 숫자는 표시하지 않는다. 과한 회전이나 점프 없이 발의 기준선을 맞춘 몸체 변형을 사용한다. PNG는 투명 배경이며 원본 생성 프롬프트는 `ShotClockAlarm.prompts.txt`에 있다.

턴마다 공과 조준 통로를 피한 테이블 내부 위치를 한 번 선택한다. 빈 공간을 찾지 못하면 화면 상단에 작게 표시한다. 이후 조준 통로가 겹치면 일시적으로 숨긴다. HUD와 큐대보다 위에 그리며 클릭을 가로채지 않는다.

싱글 연습은 제한시간이 실행 중인 경우에만 표시한다. 멀티는 현재 조작자가 선택한 테이블 좌표를 상대에게 전달한다. 메시지 도착 전에는 공을 피한 임시 위치에 표시하고, 메시지를 받으면 전달된 좌표를 적용한다. 타이머 갱신보다 먼저 온 좌표도 보관한다. 상대의 비활성 큐 조준 방향으로 자명종을 숨기지 않는다. 상대 턴에도 보이며 알람 음량은 낮아진다. 샷 시작, 타이머 정지, 시간 초과 시 숨기고 소리를 멈춘다.

리플레이는 Image 프레임, 변형, 표시 위치와 벨 이벤트를 저장한다. 정상 재생에서는 벨을 재생하고 탐색 시에는 지난 소리를 한꺼번에 재생하지 않는다. 이전 리플레이에는 새 자명종이 소급해서 추가되지 않는다.

검증 요청: `Logs/shot-clock-alarm.request`에 `validate`를 기록한다. 유니티 에디터가 프레임, 임계시간, 위치 선택, 상대 좌표 수신, 저장·읽기·탐색을 검사하고 `Logs/shot-clock-alarm-validation.json`과 `Logs/ShotClockAlarm/`의 렌더 이미지를 만든다. 실제 두 PC의 네트워크 지연과 음량은 별도 플레이 확인이 필요하다.

2026-11-23: 유니티 에디터의 자명종 검증 31개를 통과했고 세 상태의 렌더 이미지도 확인했다. 런타임/에디터 컴파일 오류는 없으며 기존 코드의 경고는 남아 있다.

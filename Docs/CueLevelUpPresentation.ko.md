# 큐대 성장과 레벨업 표시

`모두성장`의 서버 승인은 한 요청으로 저장하고, 화면에서는 파워 → 밀기 → 스핀 → 조준 → 시간 순서로 승인 가능한 항목만 하나씩 연출한다. 대기 항목은 `대기`, 현재 항목은 `성장 중`, 끝난 항목은 `완료`로 표시한다. 숫자 감소는 0.3초마다 1이며 그래프 내부 오른쪽→왼쪽 빛과 동기화한다.

각 항목의 연출이 끝나면 큐대 전체 진도 막대를 0.42초간 갱신한다. 서버의 성장 단계(`CueSteps`)와 실제 능력치 레벨이 함께 증가한 경우에만 `CueLevelUpMotion`을 자동 재생한다. 부분 바가지 승인이나 전 능력치 최대 상태에서는 레벨업을 재생하지 않는다. 숫자는 기존 큐대 헤더의 새 레벨 표시값과 같으며 이전 레벨/화살표는 표시하지 않는다.

최종 확정 연출은 대표 레벨 숫자 및 배지를 사용하지 않는다. 서로 다른 5가지 능력치의 성장 완료를 CUE LEVEL UP으로 축하한다. 큐대 상세창 위 중앙에 월계수와 금색 글자, 뒤쪽 금빛 광선 및 청록색 궤도가 포함된 투명 이미지 Celebration.png를 표시한다. 외부 팝업 박스나 확인 버튼은 추가하지 않는다. 배경은 일시적으로 어두워지고 기존 모두성장 버튼과 큐대 스킨은 연출 중 숨긴다.

진도 달성 시 막대 중앙의 작은 금빛 섬광과 아래로 갈라지는 5가닥 번개가 0~0.18초, 0.25~0.45초에 두 번 점멸한다. 두 점멸 사이에는 완전히 꺼진다. 0.5초부터 레벨업 이미지를 표시하고 전체 3.2초 후 종료한다. 대표 레벨 값은 연출에 전달하지 않는다.

성장 데이터는 화면 연출 전에 서버에서 한 번에 저장된다. 팝업을 닫으면 연출만 종료되며 다시 열어도 반복하지 않는다. Sprite와 전기 효과 머티리얼은 종료 시 해제한다. 게임 물리 난수 및 서버 성장 규칙을 변경하지 않는다.

Celebration.png는 승인한 시안에서 built-in image_gen으로 분리 제작했다. 제작 프롬프트는 CueLevelUpFinalArtPrompt.txt에 기록했다. 예전 숫자/배지/폰트 에셋은 새 연출에서 로드하지 않는다.

검증 요청은 Logs/PlayerPage/run.request 및 Logs/Bowls/ui-only.request. 실제 유니티 렌더 결과는 Logs/PlayerPage/ui-cue-level-up.png 및 ui-cue-progress-flash.png. 점멸 타이밍, 0.5초 지연, 숫자/배지/버튼 부재, UI 입력 비차단, 종료 및 재열기 상태를 검사한다.

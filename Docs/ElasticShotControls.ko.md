# 파워·팔로스루 고무줄 UI

새 표시 컴포넌트가 기존 조작 핸들의 위치를 읽어 플라스틱 프레임과 고무줄을 표시한다. 원래 스프라이트·샷 계산·네트워크 값은 보존한다. 연습과 멀티플레이에서 공통 컴포넌트를 사용한다.

- 총 이동거리 중 위쪽 30%는 팔로스루, 아래쪽 70%는 파워다. 경계의 양쪽 홈이 고정 시작점(파워 0.0)이다.
- 팔로스루는 위로, 파워는 아래로 드래그한다. 새 팔로스루 표시 거리만큼 입력 배율을 보정한다.
- 고무줄은 붉은 고무 질감을 유지한다. 당길수록 길어지고 폭이 줄어든다. 색상은 변하지 않는다.
- 놓으면 기존 샷 애니메이션의 핸들 위치를 따라 복원한다. 시작점을 통과하면 짧아진 고무줄 꼬리가 파워 손잡이 아래에서 함께 올라간다. 파워 손잡이 상단과 팔로스루 뚜껑 하단이 맞닿는다.

## 실사 이미지 적용

`MetalAtlas.png`의 금속 본체·손잡이·팔로스루 뚜껑·붉은 고무 이미지를 UV로 분리해서 표시한다. 단색 절차적 재질 대신 이미지의 조명과 질감을 그대로 사용한다. 고무줄은 메시 변형으로 늘리고, 프레임의 위아래 캡은 비율을 유지한다. 축소 시 무늬가 거칠어지지 않도록 밉맵과 삼선형 필터를 사용한다. 이미지가 누락되면 기존 절차적 표시로 대체한다.

새 이미지는 컨트롤 생성 시 읽으므로 Unity 재생 중 업데이트했다면 재생을 다시 시작한다. 생성 도구와 프롬프트는 `Docs/ElasticControlsImagePrompt.md` 참조.

## 원래 디자인으로 복귀

Unity 메뉴 `Tools > Gameplay > Elastic Controls > Restore Original Appearance`를 선택한다. 다시 적용하려면 같은 메뉴의 `Use New Appearance`를 선택한다. 실행 중에도 다음 프레임에 반영된다.

설정 파일: `Assets/Resources/Gameplay/ElasticControls/Settings.asset`의 `Use New Appearance`. 기존 이미지를 덮어쓰지 않았으므로 별도의 이미지 복원은 필요 없다.

## 금속 구조 업데이트

본체는 고정 시작점 아래의 파워 이동 영역에만 고정한다. 팔로스루 뚜껑과 연결봉은 위로 이동하고, 연결봉은 길이를 늘리지 않고 본체 내부에서 빠져나온다. 고무줄의 윗부분은 본체 상단 고정점에 연결된다. 당길수록 가늘어지고, 복원 후 손잡이 상단이 뚜껑 하단에 닿도록 표시한다. 실제 샷 계산은 기존 핸들 값을 그대로 사용한다.

검증: C# 빌드 오류 0개. 별도 Unity 렌더링에서 4개 파워 상태 및 원복/재활성화, 팔로스루 0/중간/최대에서 본체 위치·크기 불변, 연결봉 길이 불변, 손잡이와 뚜껑 접촉을 확인한다. 실전 네트워크 대전 입력 검증은 별도다.

## 시안 비율 보정

본체 높이/폭은 3.45, 파워 손잡이 폭/본체 폭은 0.94로 고정한다. 손잡이 높이와 뚜껑 높이는 각각 이미지의 가로세로 비율로 계산한다. 기존 월드 핸들의 전체 길이에 본체 이미지를 늘리지 않고 UI 전체 비율을 유지한다. 줄어든 화면 이동 거리에 맞춰 파워·팔로스루 입력 배율을 보정하며 원복 시 배율은 1로 복구된다. 금속 이미지만 어두운 회청색으로 틴트하고 고무줄 색상은 유지한다.

검증: 본체 비율 3.45와 손잡이 폭 비율 0.94 검사, 컴파일 오류 0개, Unity 네 가지 상태 렌더링 및 뚜껑 접촉·원복 검사 통과.

## 사용자 Photoshop 배치 기준 — 현재 적용 기준

이 절은 위의 자동 비율 및 30:70 설정을 대체한다. 사용자가 제공한 세 번째 이미지(1368×768)를 기준으로 본체는 x=10, y=334, w=88, h=402; 파워바는 84×92; 뚜껑은 84×39; 최대 연결봉 노출은 95px이다. 전체 화면 높이에 비례해 동일 배율로 표시하며 새 이동 거리에 맞춰 입력 배율을 보정한다. 파워/팔로스루/0.0 글씨와 고정점 장식은 숨긴다.

`ApprovedParts.png`는 사용자가 제공한 첫 번째 시안 원본을 바이트 그대로 복사한 것이다. 새로 생성한 `MetalAtlas.png`는 사용하지 않는다. 원본 색상에 흰색 틴트만 적용한다. 원본 1860×845 좌표로 각 부품을 직접 샘플링하여 임포트 해상도 변경에도 잘못된 부분을 읽지 않는다. 본체의 상단 40px와 하단 50px는 가로 배율에 맞춰 보존하고 가운데만 늘린다. 뚜껑은 고정 크기이며 그 아래의 직선 연결봉만 늘어난다. 돔 외부 배경은 UI 메시 형태로 제외한다.

검증: 1368×768 Unity 렌더링에서 기본/중간 당김/최대 당김/뚜껑 도달 4개 상태, 글씨 비표시, 본체 402:88 비율과 파워바 84:88 폭 비율, 팔로스루별 뚜껑 도달 및 기존 디자인 원복을 확인했다. 실전 대전 화면 직접 확인과는 구분한다.

# 싱글 3구·4구 s5_10 철거 해머

싱글 연습의 감정 선택 목록에서 s5_10을 선택하고 연출재생을 누르면 큰 철거 해머가 세 지점을 타격한다. 타격 시점은 시작 후 약 0.35초, 1.00초, 1.65초이며 균열은 세 단계로 확산되고 이전 타격의 균열을 유지한다. 약 2.6초부터 사라져 3.25초에 원래 테이블로 돌아온다.

- `PracticeSentimentController.Initialize`의 로컬 3구·4구 경로에서 s5_10에만 `PracticeTableDemolition`을 연결한다. 기존 멀티플레이 및 다른 감정의 애니메이션은 교체하지 않는다.
- 테이블의 메시·재질·텍스처·공 위치를 변경하지 않는다. 균열은 플레이 영역에 마스킹된 투명 스프라이트로 겹쳐 표시한다. 망치 회전·상승·반동과 콘크리트 파편·충격 광선은 코드로 움직이며 동영상을 사용하지 않는다.
- 첫 타격은 1번 그림으로 좌측, 두 번째·세 번째 타격은 3번 그림으로 우측으로 내리친다. 탑뷰에 맞지 않는 2번 옆면 그림은 타격에 사용하지 않는다. 준비 동작 0.16초 후 실제 하강은 0.09초이며 반동은 0.14초다.
- 타격당 파편은 12개이며 크기·가로세로 비율·회전 방향과 속도·명암·체공 시간이 서로 다르다. 작은 조각일수록 빠르고 멀리 날며 큰 조각은 무겁게 느리게 움직인다. 타격 방향으로 밀집된 불규칙한 부채꼴에 옆쪽·뒤쪽으로 튀는 일부 조각을 섞는다. 균등한 원형 배치는 사용하지 않는다. 각 재생 시작 때 전용 난수로 변화를 만들고, 프레임마다 난수를 다시 뽑거나 게임의 공용 난수 상태를 바꾸지 않는다.
- 자연 종료, 다른 감정 선택, 새 샷, 연습 화면 비활성화 시 시각 효과를 즉시 숨긴다. 반복 재생은 균열이 없는 상태에서 다시 시작한다. 화면/씬 종료 시 생성한 스프라이트와 오브젝트를 해제한다.

## 에셋

승인된 이미지 생성 도구 시안의 원본 RGBA 시트를 그대로 사용한다. 이미지 자체를 다시 가공하지 않고 Unity에서 셀별 스프라이트를 생성한다.

- `Assets/Resources/Gameplay/Sentiments/Demolition/HammerAngles.png`: 반실사 카툰 철거 해머, 3개 시점, 손잡이 하단 회전축.
- `Assets/Resources/Gameplay/Sentiments/Demolition/CrackStages.png`: 작은 금 → 확장 → 넓은 균열의 3단계, 투명 배경.
- Assets/Resources/Gameplay/Sentiments/Demolition/ConcreteShards.png: 거친 파단면·골재·입체 명암을 표현한 투명 콘크리트 파편 6종(3열×2행). 매 타격에 6종을 섞어 사용하고 원본 질감을 보존하도록 밝은 색상으로 표시한다. 생성 프롬프트는 Docs/S5_10ConcreteShards.prompt.txt에 보관한다.
- 생성 프롬프트 기준: 두꺼운 외곽과 단순화된 강철·목재·고무 질감의 카툰풍 철거 해머. 균열은 녹색 천 아래 회색 슬레이트가 드러나는 검은 균열과 얇은 깨진 가장자리만 표현하고, 망치·테이블·파편·먼지는 섞지 않는다.

## 검증

`Logs/practice-demolition.request` 파일을 만들면 편집기에서 원래 연습 씬의 복사본으로 3구·4구 설정을 검사한다. 선택/재생 경로, 세 지점 타격·누적 균열, 자동 종료, 취소, 반복 재생, 테이블·공 변환 보존, 종료 전후 픽셀 비교를 검사한다. 원래 편집 씬은 저장하거나 수정하지 않는다.

결과는 `Logs/practice-demolition-validation.json`, 단계별 렌더 이미지는 `Logs/Demolition/`에 생성된다.

2026-11-23: 3구·4구 설정에서 30개 검사를 통과했다. 두 설정 모두 종료 전후 원래 테이블 이미지의 평균 RGB 차이는 0이었다. 테이블 및 공의 변환도 유지됐다. Windows 빌드가 아닌 Unity 편집기의 실제 연습 씬 복사본에서 검증했다.

방향·타격 속도·파편 크기 수정 후에는 46개 검사를 통과했다. 좌측/우측 스윙 방향, 옆면 그림 미사용, 0.09초 하강, 타격당 12개의 큰 파편을 추가 검사했고 종료 전후 화면 차이는 다시 0이었다.

파편 다양화 후에는 54개 검사를 통과했다. 크기 범위·가로세로 비율 차이, 작은 파편의 높은 이동 속도, 타격 방향으로 밀집된 분포를 추가 검사했다. 자연 종료 후 화면 차이는 0이었다.

콘크리트 이미지 교체 후에는 56개 검사를 통과했다. 실제 ConcreteShards 텍스처 연결과 매 타격 6종 혼합을 추가 검사했으며, 기존 크기·속도·방향 검사 및 종료 후 화면 차이 0을 유지했다.

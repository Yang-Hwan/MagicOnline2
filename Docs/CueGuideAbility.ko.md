# 큐대 가이드 능력치

- 연습과 멀티플레이에서 수구 및 첫 적구의 예상 이동 가이드에 적용한다.
- 기존에 계산한 각 경로의 표시 길이를 100%로 삼는다. 유효 능력치 50%는 그 경로의 앞 절반, 0%는 숨김이다. 충돌 예측과 실제 물리 동작은 바꾸지 않는다.
- 첫 적구 가이드는 표시된 수구 경로가 첫 충돌 지점까지 도달했을 때만 표시한다. 쿠션을 거치는 경우에도 직선거리가 아닌 경로 누적 거리로 판단하며, 도달하지 못하면 이전 적구 가이드도 지운다. 표시된 적구 가이드 자체의 길이에는 동일한 능력치 비율을 적용한다.
- 관리자 큐대 편집에 가이드 초기 레벨과 최고 레벨을 추가했다. 기존 능력치와 동일한 성장 및 등급 계수를 적용한다. A급 50은 50%, B급 50은 45%, C급 50은 40%다.
- 기존 4개 능력치 데이터 및 이전 경기 장비 정보는 가이드 100%를 유지한다. 새 데이터는 다섯 번째 요소로 가이드를 저장한다.
- 보유 큐대와 진행 중인 경기는 기존 장비 확정 규칙을 유지한다. 상품 수정만으로 기존 보유 장비를 덮어쓰지 않는다. 관리자 회원 화면의 최신 설정 적용 기능은 기존과 같이 성장 초기화를 동반하므로 필요한 경우에만 사용한다.
- 성장한 가이드 수치는 다음 경기에 반영하며 진행 중인 경기의 길이는 변경하지 않는다.

## 검증

- Unity 및 API 빌드 성공.
- CueGuideLengthValidation: 두 ShotCtrl의 100/50/0% 표시, 꺾인 경로의 거리 기준 절단, 원본 경로 보존 및 첫 충돌 지점 도달 여부를 검증한다.
- CueAbilities.Tests: 이전 데이터 호환, 가이드 범위 검증, DB 저장, 경기 장비 확정, 성장 및 다음 경기 반영 등 전체 26개 검사 통과. 실제 회원 데이터는 변경하지 않는다.

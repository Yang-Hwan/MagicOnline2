# 2026-11-26 제작 큐대 상점 등록

오늘 생성한 디자인을 개별 색상과 시리즈별로 분리한 39개 상품이다. 목록과 임시 가격은 `DailyCueSkins20261126.json`에 기록했다. 기본·패턴형 200~350보석, 장식형 400~500보석, 신화·동물형 600~700보석이며 관리자에서 자유롭게 변경할 수 있다.

모두 A등급, 파워·팔로스루·당점·시간·가이드 초기 50/최대 100, 진도폭 100, 바가지 최대 [20,10,30,20,40], 자동 마시기 꺼짐으로 등록한다. 기존 회원의 보유 장비·재화·성장 데이터는 변경하지 않는다.

`028_daily_cue_skins_20261126.sql`은 기존 상품을 보존하며 리소스 키가 없는 상품만 추가한다. 같은 스크립트를 반복 적용해도 중복 생성하지 않는다. 다른 컴퓨터에서는 소스를 받아 API를 실행하면 마이그레이션이 적용된다. 클라이언트도 새 PNG와 코드를 포함하도록 갱신해야 한다.

`Assets/Resources/Gameplay/DailyCues20261126/`의 PNG는 승인된 시안에서 내장 image_gen으로 배경/문구를 제외해 분리한 투명 이미지다. 각 원본 시안과 행 번호는 JSON에 기록했다. 분리 프롬프트: 해당 시안의 지정 행 큐대만 원래 형태·색·비율·방향·국소 발광을 보존해 추출하고, 제목·배경·다른 큐대를 모두 제거한 투명 배경으로 제작.

`DailyCueArt`가 투명 여백을 제외한 표시 텍스처를 한 번 만들어 상점·사물함·경기에서 공유한다. 타격 끝의 중심축을 유지하며, 새 39종은 기존 프리미엄 큐대의 평면 표시 경로를 사용한다. 추가 절차형 입자/번개 애니메이션은 넣지 않고 원래 이미지의 외형을 표시한다. 서버 구매·장착·장비 스냅샷 경로는 기존과 동일하다.

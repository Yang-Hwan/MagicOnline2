# 싱글 연습 s1_4 폭탄 연출

로컬 3구·4구 연습의 감정 선택/연출재생에서 s1_4에만 `PracticeBombExplosion`을 연결한다. 기존 멀티플레이와 다른 감정의 원래 폭탄 연출은 그대로 사용한다.

- 두 폭탄이 서로 다른 지점에 0.7초 간격으로 낙하한다. 첫 충돌은 0.65초, 두 번째 충돌은 1.35초다. 각 폭탄은 별도 렌더러로 낙하·폭발·연기 단계를 겹쳐 재생한다.
- 0.65초: 폭탄이 사라지고 강한 섬광·확장하는 충격파·화염·금속 파편 18개가 나타난다.
- 섬광은 0.2초, 충격파는 0.48초에 걸쳐 사라진다. 화염은 초기/확장/쇠퇴의 세 그림으로 전환되며 약 0.95초 동안 표시된다.
- 연기는 폭발 0.26초 후부터 뒤따른다. 여러 조각이 서로 다른 위치와 크기로 확산되고 투명해진다. 연기는 0.30초에 걸쳐 나타난 뒤 팽창·이동하면서 지속적으로 옅어진다. 조각별 체공 시간도 다르며 두 연기 모두 완전히 사라진 뒤 총 4.5초에 효과를 정리한다.
- 테이블 메시·텍스처·재질과 공의 위치/물리를 변경하지 않는다. 효과는 천 영역에 마스킹된 스프라이트로 표시한다. 중단·다른 연출 선택·새 샷·화면 비활성화 시 바로 숨기며 반복 재생은 처음부터 시작한다.
- 이미지와 렌더러는 최초 재생 시 생성해 재사용하며 프레임별 이미지 생성이나 동영상 재생을 하지 않는다. 씬 종료 시 생성한 객체와 Sprite를 해제한다.

에셋: `Assets/Resources/Gameplay/Sentiments/Bomb/ExplosionAtlas.png` (3×3 투명 PNG 원본). 내장 image_gen으로 생성했으며 프롬프트는 `Docs/S1_4BombExplosion.prompt.txt`에 보관한다. Unity에서 셀별로 Sprite를 생성한다.

검증: `Logs/practice-demolition.request`를 만들면 원래 씬을 변경하지 않는 연습 씬 복사본에서 기존 s5_10 및 신규 s1_4의 3구·4구 선택/재생, 단계 순서, 중단, 반복, 원상복구를 검사한다. 결과는 `Logs/practice-demolition-validation.json`, 폭탄 단계별 이미지는 `Logs/Demolition/*-bomb-*.png`에 기록한다.

2026-11-23 검증: 기존 s5_10 56개 및 신규 s1_4 26개, 합계 82개 검사를 통과했다. 3구·4구 모두 폭탄 낙하/섬광/충격파/화염/파편/연기 단계와 종료·취소·반복을 검사했으며 종료 전후 테이블 렌더 이미지의 RGB 차이는 0이었다. 편집기 복사 씬은 비활성화 수명주기를 자동 실행하지 않으므로 해당 검사는 OnDisable 콜백을 직접 호출했다. Windows 빌드는 실행하지 않았다.

두 발 연속 낙하 및 연기 소멸 개선 후 총 94개 검사를 통과했다. 두 번째 낙하의 지연, 독립적인 두 번째 폭발, 서로 다른 타격 지점, 연기 팽창 중 알파 감소, 종료 직전 두 연기의 완전 소멸을 추가 검사했다. 종료 전후 원래 테이블의 화면 차이는 0이었다.

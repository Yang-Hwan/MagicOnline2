# 회원별 재화 표시 및 큰 금액 지원

2026-10-27 적용.

- 회원관리 AdminReadService와 /api/me의 GameData.Profile은 동일한 wallets 테이블을 회원 UUID로 조회한다. 클라이언트는 인증된 /api/me → BackendGame.UserMainData → 상단 UI 경로를 사용한다.
- 메뉴가 활성화되거나 앱으로 돌아오면 서버 데이터를 다시 읽고, 메뉴가 열린 동안 30초마다 갱신한다. 동시 중복 조회는 방지하며, 일시적인 연결 실패 시 마지막 값을 유지한다. 다른 계정으로 전환된 응답은 기존 BackendGame.LoadAsync의 소유자 검사로 무시한다.
- 보석 값 영역 190px, 코인 값 영역 282px (1672×941 기준). 글자 32px에서 최소 22px까지 자동 조절, 줄바꿈 없음, 우측 정렬, 로캘과 무관하게 쉼표 단위 구분을 적용한다. 아이콘과 충전 버튼도 함께 재배치했다.
- Coin은 기존 long/DB bigint, Jem은 기존 int를 유지한다. 요청한 100,000,000,000 코인과 10,000,000 보석을 충분히 표현하므로 DB 스키마 변경은 필요 없다.
- Unity BottomMenuValidation 통과: 두 최대 예시 금액의 정확한 문자열, 한 줄 표시, 잘림 없음, 16:9/4:3/울트라와이드 렌더 및 탭 클릭 영역 검사. Implemented/wallet-max-test.png는 검증용 메모리 값이며 실제 회원의 DB 금액은 변경하지 않았다.

# 메인메뉴 그래피티 시안

- 산출물: `home-menu-mockup.png`
- 생성 방식: built-in image_gen. 시안이며 Unity 화면에는 아직 적용하지 않음.
- 배경: 사용자가 첨부한 검정 벽돌, 노랑/흰색 그래피티, 당구공과 큐대 이미지.
- 기존 화면 참고: `Assets/Common/Sprites/main_page_01.png`, `PnlPrime.cs`.
- 닉네임, 레벨, 진행률, 재화, 우편 개수는 시안용 예시 값.
- 상단 프로필 및 재화/충전/설정, 우측 6개 아이콘 버튼, 하단 5개 주요 메뉴 구성.
- 선물함·기타 버튼은 요청에 따른 디자인 제안이며 기능 구현을 의미하지 않음.

# 3구·4구 연습 감정 연출

이 문서의 적용 범위: 로컬 3구 및 4구 연습. 멀티플레이는 별도의 어댑터로 확장했으며 `MultiplayerSentiment.ko.md`를 참고한다. 리플레이에는 신규 판정을 적용하지 않는다.

씬: `Assets/Practice/Scenes/TableSet07.unity`

- 신규: `Table > Addition > Sentiment`
- 구감정 보관: `Table > Addition > MovStorys`
- 하단 `구감정` 해제: 신규 감정, 체크: 구감정. 선택 목록과 연출재생도 함께 전환한다.
- 오브젝트 선택 시 Inspector에서 원본 이미지의 해당 영역을 미리 볼 수 있다. `width`, `duration`으로 크기와 시간을 조절한다.

## 판정과 재생

### 기존 애니메이션의 신규 감정 편입

`MovStorys` 원본은 보존하고 아래 12개를 `Sentiment`에 독립 복사했다. 하위 파티클·마스크·애니메이터와 내부 참조를 함께 복사한다.

| 감정 | 신규 이름: 원본 효과 |
|---|---|
| 분노 | s1_4: BombDebris |
| 좌절 | s5_4: CrowFly / s5_5: DeadLeaves / s5_6: GlassBroken / s5_7: SnowStorm / s5_8: DarkCloud / s5_9: DogBone / s5_10: PongHammer / s5_11: TearCry |
| 기쁨 | s6_5: MusicNote |
| 안도 | s8_4: BellyLaugh / s8_5: LightEmit |

- 글자와 애니메이션이 모두 있는 감정은 유형을 50:50으로 선택한 뒤 해당 유형 안에서 랜덤 선택한다. 같은 유형의 직전 변형을 가능한 경우 제외한다.
- DarkCloud는 수구의 월드 좌표를 부모 로컬 좌표로 변환한다. DogBone, PongHammer, TearCry, BellyLaugh는 발동 순간 수구 월드 위치를 전달하고, LightEmit은 PS 발사 위치를 그 지점으로 옮긴다. 계속 수구를 추적하지 않는다.
- 나머지는 기존 테이블 전체 연출 위치를 유지한다. 글자용 공 회피 배치는 애니메이션에는 적용하지 않는다.
- 연출 종료, 새 감정·새 샷·구감정 전환·화면 비활성화 시 Tween과 파티클을 정리한다. 반복 재생 시 원래 자식 Transform을 복원한다. 무한 파티클 방지를 위한 최대 재생 시간은 기본 8초다.
- 신규 목록의 `연출재생` 및 Inspector 재생 버튼은 현재 차례의 수구 위치를 사용한다. 원본 효과명은 Actor의 phrase와 목록에 표시한다.
- 씬 배치 오브젝트를 재사용하며, Transform·파티클 목록은 초기화 시 캐시한다. 기존 애니메이션의 DOTween 시퀀스 생성 비용은 재생 시 남아 있다.

기존 게임 판정은 변경하지 않는다. 접촉 관찰은 충돌 진입 시점에 기록한다. 3구 득점은 기존 `OnScoreChanged`에 반응하고, 4구 득점과 최종 실패는 `OnPracticeShotResult`를 따른다. 새 샷마다 기록을 초기화한다.

- 저속 기준: 속력 0.7 이하.
- 키스: 같은 적구 재접촉 또는 이번 샷 시작 위치에서 0.03 이상 움직인 적구와 접촉. 이전 샷 이동 기록은 사용하지 않는다.
- 격려: 첫 적구 접촉 후 남은 적구가 1.6 이내이며, 직선 예측상 중간 쿠션/다른 공 없이 맞을 때. 3구는 필요한 쿠션 수 충족을 확인한다. 4구는 쿠션 횟수 조건 없이 남은 빨간 공(id 2/3)만 대상으로 하며, 상대 수구는 제외한다.
- 실망: 저속 접근 후 목표를 살짝 지나친 기록. 아직 실패를 확정하지 않는다.
- 성공: 키스 기록이 있으면 감사, 없고 저속 지나침 기록이 있으면 안도, 나머지는 기쁨. 3구는 정지를 기다리지 않고 확정 이벤트에 반응한다.
- 쿠션 부족으로 두 번째 적구에 닿은 3구 실패는 4구 파울과 구분한다. 분노 문구는 3구에서 연출재생으로 확인할 수 있지만 파울이 없는 정상 3구 샷에서 억지로 발생시키지 않는다.
- 4구는 빨간 공 둘을 맞혀도 성공을 즉시 표시하지 않고 공이 멈춘 뒤 최종 판정을 기다린다. 두 적구 접촉 후에는 더 이상 격려·실망 대상으로 같은 적구를 추적하지 않는다.
- 4구 상대 수구 접촉은 키스로 기록하지 않는다. 기존 경기 로직에서 파울이 확정되면 충돌 당시 속력으로 분노(0.7 초과) 또는 좌절(0.7 이하)을 표시하고 그 샷의 추가 감정을 차단한다. 접촉 당시 속도를 보관해 충돌 직후 감속으로 분노가 좌절로 잘못 바뀌는 것을 방지한다. 정지 후 확정되는 무접촉 파울은 좌절이다.
- 콘솔에는 실제 표시된 감정과 샷 종료 시 감정 흐름을 출력한다. 미리보기는 샷 기록에서 제외한다. 로깅은 Unity Editor 및 Development Build에만 포함한다.
- 한 샷의 동일 감정 중복을 막으며, 다른 감정 전환은 허용한다. 같은 분류의 직전 문구를 제외하여 랜덤 선택한다.
- 위치는 `Table/ClothSpace`의 실제 안쪽 사각형을 화면에 투영해 정한다. 글자의 최대 확대·흔들림·상승 범위 전체가 이 영역 안에 들어와야 한다.
- 수구와 적구의 화면상 반지름에 여유 간격을 더하고, 약 0.35초 앞의 직선 이동 구간도 피한다. 가까운 주변 8곳과 테이블 내부 격자 35곳에서 빈 공간을 찾으며, 수구 진행 방향 반대편을 우선한다.
- 공간이 부족하면 크기를 85%, 70% 순서로 줄여 다시 찾는다. 그래도 안전한 공간이 없으면 그 연출은 생략한다.
- 위치는 재생 중 고정한다. 초당 최대 20회 공 접근을 확인하여 0.18초에 걸쳐 조기 페이드한다. 카메라 변경으로 테이블 경계를 벗어나는 경우에도 종료한다. 한 번에 하나만 재생한다.

## 성능 및 검증

글자 27개와 애니메이션 12개, 총 39개 감정은 씬에 저장된 오브젝트이며, 초기화 때 목록을 수집한다. 글자는 투명 이미지 9장을 공유하고 UV로 선택한다. 매 샷 이미지 생성/파괴를 하지 않고 공용 UI 하나를 재사용한다. 저속 근접 관찰은 초당 최대 10회, 경로 확인은 고정 버퍼 `SphereCastNonAlloc`을 쓴다. 기존 3구·4구 연습의 프레임별 감정 예측/말풍선은 중복되지 않게 제외한다. 구감정의 원본 애니메이션 내부 동작은 그대로 보존한다.

애니메이션 편입 검증: 분리된 Unity Play Mode에서 씬에 복사한 실제 12개 효과를 각 3회(총 36회) 재생했다. 이동된 부모 아래에서도 수구 좌표가 맞는지, 반복 재생 후 Tween·파티클이 정리되는지 확인했다. 전체 연습 경기 화면의 시각 검증과 성능 프로파일링은 별도다.

별도 Unity 검증에서는 실제 신규 컨트롤러를 간소화된 경기 이벤트 공급자에 연결하여 득점 즉시 반응, 감사/안도 분류, 3구 쿠션 부족 실패, 직접 접근, 연속 랜덤 중복 방지, 구감정 전환 및 이미지 알파를 확인했다. 전체 연습 경기의 실제 플레이 및 게임 전체 프레임 성능 검증을 대신하지 않는다.

4구 추가 검증: 쿠션 없이 남은 빨간 공 접근, 상대 수구의 경로 차단, 종료 전 성공 보류, 두 적구 접촉 후 파울 우선, 흰/노랑 수구 각각의 고속·저속 파울, 파울 후 감정 차단, 감사·안도 및 정지 후 무접촉 파울. 3구 회귀와 배치·페이드 검증도 함께 실행했다.

## 이미지 제작

내장 imagegen으로 기존 승인 시안에서 배경/제목을 제거해 투명 PNG 시트를 생성했다. 게임용 파일은 `Assets/Practice/Art/Sentiment/`에 보관한다. 파일 픽셀을 별도 프로그램으로 수정하지 않고 Unity에서 UV로 영역을 선택한다.

프롬프트 공통: 기존 문구/색/그래피티 붓글씨를 유지, 제목과 어두운 배경 제거, 각 문구를 독립 셀로 배치, 실제 투명 알파, 셀 간 여백, 새 텍스트 금지. 감사 시트는 크림·분홍 붓글씨로 고마워/땡큐/꾸벅/죄송 ㅎㅎ를 2×2로 재생성했다.

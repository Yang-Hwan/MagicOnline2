# 공식 길드전과 시즌

## 화면과 진입

홈 → 길드 → **길드전**에서 시즌 현황 / 길드 순위 / 기여도·보상을 확인한다. 기존 길드 홈·길드원·찾기·친선경기는 그대로 유지한다.

- 시즌 현황: 4주 진행 상태, 시작/종료일, 남은 기간, 내 길드 등급·순위·점수·전적, 오늘 반영 경기 수, 최근 결과, 4구/3구 공식전 매칭.
- 길드 순위: 시즌 점수 기준 순위와 전적, 브론즈/실버/골드/다이아 필터, 페이지 이동, 내 길드 위치.
- 기여도·보상: 개인 반영 경기 수와 순 기여 점수, 길드 내 기여 순위, 예상 보상과 확정된 이전 시즌 보상 수령.
- 길드 찾기의 시즌 보상함: 현재 길드가 없어도 이미 확정된 보상과 획득한 시즌 문장을 조회·수령할 수 있다.

## 확정한 초기 운영값

시즌은 한국 시간 2026-11-02 00:00을 기준으로 정확히 28일마다 순환한다. 첫 시즌은 11월 29일까지이며 다음 시즌은 11월 30일 00:00부터다. 다음 시즌 등급 점수는 1,000점으로 초기화하고 이전 시즌 점수·순위·기여도·보상 원장은 보관한다.

공식전은 입장 무료이며 승리 +24, 패배 -12, 무승부 +4점이다. 길드 점수의 최솟값은 0이다. 개인 기여도는 참여 경기의 점수 증감을 합산한다. 하루 최초 5경기까지 참여할 수 있고 한국 시간 자정에 횟수가 초기화된다. 매칭 중인 유효 예약도 한도에 포함해 동시 요청으로 초과하지 못하게 한다. 시작 전 취소·무효 경기는 기여도와 완료 경기 수에 포함하지 않는다.

같은 상대와는 하루 한 번만 점수를 반영한다. 소속이 다른 길드, 같은 경기장, 길드 점수 차이 400 이하, 레벨 차이 10 이하인 대기자를 서버가 연결한다. 따라서 조건에 맞는 다른 길드원이 동시에 대기해야 시작할 수 있다. 상대가 없을 때는 매칭을 유지하거나 취소할 수 있다. UI에서는 종목별 첫 번째 30분 이하 경기장을 사용한다. 시즌 마감 35분 전부터 새 매칭을 중단한다.

| 점수 | 등급 | 종료 보상: 코인 / 보석 |
|---|---|---|
| 0~999 | 브론즈 | 5,000 / 20 |
| 1,000~1,399 | 실버 II | 15,000 / 50 |
| 1,400~1,799 | 실버 I | 15,000 / 50 |
| 1,800~2,199 | 골드 II | 30,000 / 100 |
| 2,200~2,599 | 골드 I | 30,000 / 100 |
| 2,600~2,999 | 다이아 II | 60,000 / 200 |
| 3,000 이상 | 다이아 I | 60,000 / 200 |

각 보상에는 해당 시즌·등급 문장 소유 기록도 포함한다. 현재 문장 소유는 보상 목록에서 확인할 수 있으며 별도 문장 장착 메뉴는 이번 범위에 포함하지 않았다.

## 매칭과 경기 결과

`POST /api/guild-league/queue`에서 서버가 경기 ID와 상대를 발급한다. Unity 두 클라이언트는 `guild-{경기ID};{경기장}` 비공개 Photon 방으로 입장한다. 참가자 ID를 방 입장과 서버 경기 등록에서 모두 검사한다. Photon 방장 순서와 서버 큐 진입 순서가 달라도 같은 티켓으로 등록할 수 있다.

친선전의 로컬 결과 표시를 사용하는 대신 기존 인증 경기의 등록·양측 준비·장비 스냅샷·하트비트·결과 정산 경로를 사용한다. 공식전 규약은 입장/상금/점수별 코인 이동이 0이며 일반 전적에는 공식 경기로 기록한다. 경기 이력 `MatchMode`는 `GuildWar`다. 점수별 코인 효과를 표시하지 않고 결과 화면에서는 재대결을 막는다. 다음 공식전은 새 매칭으로 시작한다.

길드 점수·개인 기여도·경기 완료 상태는 기존 영구 정산 영수증과 같은 DB 트랜잭션에서 기록한다. 양측 결과가 일치해야 정상 결과를 확정하며, 기권·연결 종료는 기존 서버 판정 규칙을 공유한다. 불일치 결과는 길드전에서 무효 처리해 시즌 마감을 막지 않는다. 기존 경기 보고와 분쟁 기록은 보관한다. 이는 양측 인증 보고를 검증하는 기존 구조이며 서버에서 당구 물리를 재시뮬레이션하는 방식은 아니다.

실제 경기 등록 시 소속 길드를 재확인하고 이후 경기 점수는 확정된 소속으로 귀속한다. 장비는 경기 등록 시 스냅샷으로 고정한다. 탈퇴·추방·회원 삭제 시 대기열과 미등록 예약을 취소하며, 등록된 경기는 기존 경기 정산이 마무리한다.

## 시즌 종료와 수령

서버가 15초마다 시즌 종료를 확인한다. 종료 전에 시작한 등록 경기가 남아 있으면 정산을 기다린다. 미등록 매칭 티켓은 2분 뒤 만료한다. 모든 등록 경기가 정산 또는 무효 처리되면 최종 순위와 수령 대상을 확정한다.

해당 길드에서 공식전 10경기 이상 참여하고 **시즌 종료 시점에 해당 길드 소속이었던 회원**이 대상이다. 가입·탈퇴 이력을 별도 보관하므로 마감 처리 후 늦게 조회하거나 시즌 종료 이후 탈퇴해도 종료 시점의 자격을 복원한다. 정지·삭제된 회원에게는 지급하지 않는다.

수령은 지갑 잠금, 시즌별 회원 고유 지급 행, 영구 `wallet_ledger`를 같은 트랜잭션으로 처리한다. 동시 클릭이나 응답 유실 후 재시도에도 한 번만 지급한다. 시즌이 끝나기 전에는 예상 보상만 표시하고 실제 지급을 허용하지 않는다.

## 코드와 검증

- DB: `018_guild_league.sql` — 시즌, 점수, 대기열, 예약/결과, 기여도, 보상과 가입·탈퇴 이력.
- 서버: `GuildLeague*.cs`; `Matches`에서 공식 규약 확인, `PostgresSettlementStore`에서 원자적 정산.
- Unity: `BottomMenuView.GuildLeague.cs`, `PunNetwork.GuildWar.cs`와 기존 Photon/결과 화면 연결.
- `dotnet run --project Server/GuildLeague.Tests/GuildLeague.Tests.csproj`: 실제 PostgreSQL 임시 스키마에서 32개 검사. 양측 보고, 취소, 반복 상대·하루 한도, 무효·분쟁, 28일 전환, 동시 보상 지급, 탈퇴 후 수령 이력, 영구 원장을 검증한다.
- `python Server/GameApi/Run-GuildLeagueSmoke.py`: 실행 중 API/관리자 사이트에서 검증 계정 2개와 전용 경기장으로 HTTP 매칭·준비·양측 결과 제출·점수/기여도 갱신을 확인한다. 이후 해당 계정과 경기장만 관리자 폼으로 정리한다.
- `Tools / Magic Online / Validate Guild Screens`: 기존 4개 길드 화면과 시즌 현황·순위·보상 화면을 렌더링한다. 공식전 무료 규약과 수령 버튼도 검증한다.

실행 중인 Unity 플레이는 중단하지 않았다. 코드 반영은 플레이 종료와 재시작 또는 새 클라이언트 빌드 후 가능하다. 실제 두 클라이언트의 Photon 경기 전체 실행은 이번 자동 검증에 포함하지 않았다.
